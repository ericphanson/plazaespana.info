# Log Analyzer Aggregate Data

This directory is legacy documentation for aggregate analytics generated by `log-analyzer` on production.
The canonical published outputs are served from NFS at `/analytics/` and mirrored as JSON backups to Bunny storage.

## Privacy Guarantees

These files are intended to be safe for a public repository:

- Included:
  - Aggregate hourly/monthly counts
  - Estimated unique visitors (HLL)
  - Top paths with query strings stripped
  - Status code, browser, platform, and referrer-category totals
- Excluded:
  - Raw logs
  - Individual IP addresses
  - Full User-Agent strings
  - Full referrer URLs
  - Query parameters in stored paths

## Publish Flow

1. NFSN cron runs `/home/private/bin/log-analyzer-weekly.sh`.
2. Publish script validates privacy constraints, updates `/home/private/log-analyzer-data`, and rebuilds `lifetime.json` from persisted monthly JSON files.
3. Public report/data are served from:
   - `/home/public/analytics/report.html`
   - `/home/public/analytics/data/*.json`
4. JSON backups are mirrored to Bunny with immutable-month safeguards (older month files are write-once).

## Files

- `lifetime.json`: cross-month totals and HLL state.
- `YYYY-MM.json`: per-month analytics snapshots.
- `report.html`: static summary report served publicly from NFS Apache.
