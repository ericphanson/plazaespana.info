# Log Analyzer Aggregate Data

This directory stores synchronized aggregate analytics generated by `log-analyzer` on production.

## Privacy Guarantees

These files are intended to be safe for a public repository:

- Included:
  - Aggregate hourly/monthly counts
  - Estimated unique visitors (HLL)
  - Top paths with query strings stripped
  - Status code, browser, platform, and referrer-category totals
- Excluded:
  - Raw logs
  - Individual IP addresses
  - Full User-Agent strings
  - Full referrer URLs
  - Query parameters in stored paths

## Sync Flow

1. NFSN cron runs `/home/private/bin/log-analyzer-weekly.sh`.
2. That script writes aggregate outputs into `/home/private/log-analyzer-data`.
3. GitHub Actions workflow fetches those files and opens/updates a PR.
4. The sync script enforces privacy checks before commit:
   - no IPv4-like patterns
   - no query-string paths in JSON top paths

## Files

- `lifetime.json`: cross-month totals and HLL state.
- `YYYY-MM.json`: per-month analytics snapshots.
- `report.html`: static summary report (optional; synced when present).
